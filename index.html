Setup Guide

  1. Open your Google Sheet with the sales data
  2. Go to File → Share → Publish to web
  3. Select the Sales Data sheet (not "Entire Document")
  4. Choose Comma-separated values (.csv) as the format
  5. Click Publish and copy the URL
  6. Paste the URL above and click Sync

Note: The dashboard will cache data locally. Click "Sync Now" anytime to fetch the latest data from your Google Sheet.
